# T-MTR-08 — Motor Load Test procedure

Configuration: rover-alpha Rev C with MTR-24-220, MCTRL-8A, DRV-8A, 24 V supply, and 8.0 kg payload. Run level cruise, curb start, and 12° grade for 10 minutes. Record output torque, phase current, controller temperature, speed tracking, and J12 43025-0400 power-contact temperature.

Acceptance: torque margin ≥10%; peak current ≤8.0 A; controller case ≤75 °C; J12 rise ≤25 °C; speed error ≤5%.
